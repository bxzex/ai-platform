# AI Platform

Chat with a language model that runs on your own computer, inside the browser tab.

Live: https://bxzex.github.io/ai-platform/

Press Initialize Model and it downloads the weights once. After that it runs on your GPU through WebGPU using Web-LLM, and keeps working offline. Messages never leave your machine and there's no tracking. Your chat history stays in local storage.

React 19 and Vite.
